# 程序设计思路

本文整理自课题答辩的“实验原理”部分，说明界面选择、LED 点火、红外传感器三个模块的设计思路。

## 1. 界面及选择程序设计（main.c / lcd_show.c）

设计目标是实现一个用户友好的菜单系统：能够响应用户输入（按键），并在液晶屏上实时反馈当前选择。

- **界面元素**：一个菜单项列表，以及用于导航与确认的 4 个物理按键（向上、向下、确认、取消）。
  这些元素构成用户与嵌入式系统交互的基础。
- **状态变量**：selected 记录当前选中的菜单项索引（0~3），up / down / confirm / cancel
  分别表示对应按键是否被按下。
- **输入处理**：主循环中判断按键状态。按下“向上”或“向下”时更新 selected，
  并限制在列表边界之内（0 与 3）；每次更新后调用 LCDClear() 清屏，为新的显示内容做准备。
- **界面刷新**：lcd_mainUI() 根据 selected 在对应行显示选中光标（自定义字形 0xA1FA），
  并显示四个菜单项：单发点火 / 双发点火 / 连发点火 / 其他设置。
- **确认与取消**：按下“确认”后清除 LCD 显示、延时 100 ms 防抖，进入该项对应的功能界面，
  并在“取消”未按下的期间循环执行 lcd_func() / led_func()；
  按下“取消”即退出该循环，回到主菜单。“其他设置”下另有一级子菜单
  （红外传感开关 / 发射周期调节），同样遵循“确认进入、取消退出”的规则。

菜单结构：

```text
主菜单
├─ 单发点火        -> led_func(0)：单次点火
├─ 双发点火        -> led_func(1)：连续两次点火
├─ 连发点火        -> led_func(2)：循环点火，至药量耗尽或取消键按下
└─ 其他设置        -> 子菜单
   ├─ 红外传感开关 -> OLED_Sensor()：开启/关闭传感器触发
   └─ 发射周期调节 -> OLED_Freq()：10~9990 ms，步进 10 ms
```

## 2. LED 点火程序设计（LED.c）

### led_single() —— 单次点火

设计初衷是实现单个 LED 的点亮与熄灭，用发光二极管的闪烁模拟点火节点输出的电子脉冲。

- 接收指向整数的指针 led_count，该变量存储当前应被点亮的 LED 索引；
- 内部用一个初值为 0x01 的无符号字符 led_state，通过左移生成“只有一位为 1”的 8 位数据，
  这个 1 的位置即对应应该点亮的 LED；
- 取反后写入 LED 寄存器（P0），从而点亮对应 LED（低电平有效）；
- 延时 freq 毫秒后把 LED 全部关闭，准备下一次点亮；
- 内含检查机制：led_count 达到 7 时复位为 0，实现 8 路点火节点的循环点亮。

### led_func() —— 点火方式控制

更高一层的控制器，依据 selected 决定点火节奏，count 指向剩余操作次数，freq 为点火周期。

- **selected == 0（单发）**：若 *count > 0，则先递减 *count、刷新 OLED 显示，再执行一次
  led_single()；否则只显示当前次数。
- **selected == 1（双发）**：执行一个最多循环两次的 for 循环，每次循环都重复上述动作。
  该结构保证即使剩余次数在第一次迭代后变为 0，也不会执行第二次点火。
- **selected == 2（连发）**：若 *count > 0 且取消键未按下（cancel == 1），进入 while 循环，
  循环递减 *count、刷新显示并点火；当 *count 变为 0 或 cancel 变为 0 时结束。
  循环结束后统一延时 100 ms。

## 3. 传感器程序设计（sensor.c）

函数首先检测 _switch 的值，该值决定“其他设置”中是否启用了传感器功能。

- **_switch == 0（传感器开启）**：先把 P2.0 置 0（开发板自带 LED，低电平有效），
  起到传感器状态指示作用；接着判断 P2.1（开发板自带按键，低电平有效）是否被按下。
  按下后清空 OLED 内容并显示当前剩余次数，然后进入 while 循环：
  只要取消键未被按下，循环持续进行；循环内部若 P3.2 为 0（红外传感器被触发），
  则检查剩余次数 *count——大于 0 时递减、刷新显示并按 freq 频率执行一次点火；
  不大于 0 时仅刷新显示。
- **_switch == 1（传感器关闭）**：将 P2.0 置 1，关闭开发板上的状态指示灯。

## 4. 整体流程

```text
上电复位
  └─ 端口初始化（P0~P7 全部准双向口）-> delay_ms(100)
     └─ LCDInit() / OLED_Init() -> OLED_Clear() / LCDClear()
        └─ 主循环
           ├─ sensor(sensor_switch, &led_count, frequency, &count)
           ├─ OLED_Main(sensor_switch, frequency)   显示剩余药量/周期/传感器状态
           ├─ choose(&selected)                     上下键调整菜单选择
           ├─ lcd_mainUI(selected)                  刷新菜单与光标
           └─ 确认键按下
              ├─ 清屏，显示剩余药量（非“其他设置”项）
              └─ while(取消键未按下)：lcd_func(...) 刷新界面；确认键 -> led_func(...) 执行点火
```
