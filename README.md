# 超高射频火炮全电子化发射装置 · 点火控制系统

> Ultra-high-rate RF gun electronic ignition controller — STC15W4K56S4 firmware

基于 **STC15W4K56S4** 单片机的全电子化电子点火控制系统固件。系统通过按键与屏幕构成的人机交互界面，
实现以预定射击频率进行**单发 / 双发 / 连发**点火控制，支持**红外传感器自动触发连发**，并用 LED 灯组
模拟点火节点输出的电子脉冲，用于模拟发射试验验证。

本仓库为科研训练课题《超高射频火炮全电子化发射装置的硬件开发及软件编制》的软件部分整理版。
原始工程为 Keil uVision（MCS-51）工程，源码中文注释原为 GBK 编码，本仓库已统一转为 UTF-8 with BOM。

## 功能特性

| 功能 | 说明 |
| --- | --- |
| 单发点火 | 按一次确认键，点亮一个点火节点（LED）模拟一次击发 |
| 双发点火 | 连续执行两次单发动作，模拟双发 |
| 连发点火 | 在未按下取消键期间连续击发，直至剩余药量耗尽或人工急停 |
| 发射周期调节 | 10 ms ~ 9990 ms 范围、10 ms 步进可调，决定相邻两次击发的间隔 |
| 红外传感开关 | 打开后由红外传感器（P3.2）触发射击；关闭时手动控制 |
| 剩余药量显示 | 初始 50 发，每次击发递减，OLED 实时显示 |
| 急停 / 继续 | 通过取消键（P2.7）中断连发或传感器触发循环 |
| 双屏显示 | LCD12864 显示菜单与选中项，0.91 寸 OLED 显示参数与状态 |

## 系统组成

- **主控**：STC15W4K56S4（STC15W 系列，Keil C51 工具链）
- **显示**
  - LCD12864（ST7920 控制器，8 位并行接口）——主菜单界面
  - 0.91 寸 OLED（SSD1306，128x32，软件模拟 I2C）——参数与状态
- **输入**：4 个按键（上 / 下 / 确认 / 取消）+ 红外触发输入
- **传感器**：YL-62 红外避障传感器模块（探测距离可由电位器调节）
- **演示输出**：P0 口 8 路 LED 灯组，低电平点亮，模拟点火节点脉冲

## 硬件与引脚分配

完整引脚表与开发环境搭建步骤见 [docs/hardware.md](docs/hardware.md)。摘要如下
（端口默认均为准双向口，即 PnM1 = 0、PnM0 = 0）：

| 功能 | 引脚 |
| --- | --- |
| 向上 / 向下 / 确认 / 取消 按键 | P2.4 / P2.5 / P2.6 / P2.7（低电平有效） |
| 点火节点模拟 LED 灯组 | P0.0 ~ P0.7（低电平点亮） |
| LCD12864 控制线 RS / RW / E / PSB / RESET | P4.0 ~ P4.4 |
| LCD12864 数据总线 | P6 |
| OLED 时钟 SCL / 数据 SDIN | P1.4 / P1.3 |
| 红外传感器状态指示 / 板载按键 / 红外触发输入 | P2.0 / P2.1 / P3.2（低电平有效） |

系统主时钟在 [firmware/Keil_C51/delay.h](firmware/Keil_C51/delay.h) 中定义为 MAIN_Fosc = 22118400L（22.1184 MHz）。

## 编译与烧录

**编译**（Keil uVision5 + C51 工具链）

1. 安装 Keil uVision5 与 C51 编译器，并通过 STC-ISP 的“Keil 仿真设置”把 STC15 系列型号与头文件装入 Keil。
2. 打开 firmware/Keil_C51/超高射频火炮.uvproj。
3. Rebuild（F7）。工程 Device 记录为 STC15W4K32S4 Series，实际目标芯片为 **STC15W4K56S4**。
4. 生成的 .hex 位于工程的 Objects/ 目录（该目录已被 .gitignore 排除，需要自行编译生成）。

**烧录**（STC-ISP，本次开发使用 V6.90）

1. 安装 USB 转串口驱动（核心板使用 CH340）。
2. STC-ISP 选择型号 STC15W4K56S4，选择 Objects/超高射频火炮.hex。
3. 冷启动上电下载，等待“操作成功”。

[tools/烧录说明.md](tools/烧录说明.md) 保留了 2024-10-22 的实际烧录记录（芯片 ID F528C62F03B136，
最终固件 21599 字节、程序大小 7417 字节、校验和 0x00084915），可用于核对固件版本。

## 源码说明

- **main.c** — 端口初始化（P0~P7 全部设为准双向口）、LCD 与 OLED 初始化；主循环依次执行
  sensor() -> OLED_Main() -> choose() -> lcd_mainUI()；按下确认键后进入该菜单项的详细界面，
  在取消键未按下期间循环执行 lcd_func() / led_func()。
- **LED.c** — led_single() 以 0x01 << led_count 取反后写入 P0，点亮一个点火节点，
  延时 freq ms 后熄灭，led_count 在 0~7 之间循环；led_func() 按菜单项实现单发 / 双发 / 连发三种节奏。
- **sensor.c** — 传感器开启（_switch == 0）且板载按键 P2.1 按下后，等待 P3.2 上的红外触发，
  每触发一次递减剩余药量并执行一次点火；_switch == 1 时通过 P2.0 关闭状态指示。
- **lcd_show.c** — LCD12864 界面：主菜单四项（单发点火 / 双发点火 / 连发点火 / 其他设置）、
  设置子菜单（红外传感开关 / 发射周期调节）与选中光标（自定义字形 0xA1FA）。
- **oled_show.c** — OLED 界面：剩余药量、发射周期（四位数字 + ms）、传感器开关状态，
  以及传感器开关设置页与发射周期调节页（上 / 下键以 10 ms 步进调整，范围 10~9990）。
- **oled.c / oledfont.h** — SSD1306 软件 I2C 驱动（起止信号、字节写、显存刷新）与中英文字模。

## 设计要点与已知限制

**设计要点**

- 界面与逻辑分离：显示函数只负责绘制，功能函数只负责动作，模块之间通过 global.h 声明耦合。
- 交互状态集中在少量变量中（selected、sensor_switch、frequency、count、led_count），便于维护。
- 采用“确认进入 / 取消退出”的两级菜单结构，急停与继续由取消键统一控制。
- 用 LED 闪烁模拟点火节点输出电子脉冲，可在不具备实弹条件时直观验证系统功能。

**已知限制**（来自课题总结，供后续改进）

- 点火间隔由 delay_ms() 软件延时产生，存在延时误差与数据取整误差；
  建议改用单片机内部定时器并优化计算方法以提高控制精度。
- 目前仅支持单管单一射速，尚未实现多管配合、多弹种装填与按管号选择发射。
- 点火节点演示电路为 8 路 LED（led_count 0~7），实际点火节点数量需按武器身管数扩展。
