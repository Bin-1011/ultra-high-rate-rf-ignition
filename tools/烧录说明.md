# STC-ISP 烧录说明与历史记录

## 1. 烧录步骤

1. **安装 USB 转串口驱动**：核心板使用 CH340 芯片，运行驱动包中的 HL-340.EXE，
   点击 INSTALL，弹出“驱动安装成功”即表示安装成功。
2. **向 Keil 添加 STC15 型号与头文件**（如需在本机编译）：
   打开 STC-ISP，在右侧选择“Keil 仿真设置”，选择芯片型号后点击对话框，
   指定 Keil 安装路径并确定，提示“STCMCU 型号添加成功”即完成。
3. **选择芯片与固件**：STC-ISP 中选择单片机型号 **STC15W4K56S4**，
   并选择 Keil 编译生成的 Objects/超高射频火炮.hex。
4. **下载**：点击“下载/编程”，然后给开发板冷启动上电（重新上电），等待提示“操作成功”。
5. 下载完成后上电复位，LCD12864 显示主菜单，OLED 显示剩余药量与发射周期等状态。

> 说明：本仓库不包含编译中间产物，Objects/ 目录已被 .gitignore 排除；
> 使用前请先用 Keil 重新编译生成 .hex。
